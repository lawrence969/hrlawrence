# HR Lawrence

i want to build an app for jewellers. this app will manage 2 types of client orders, the first will manage workflow for repairs, a client brings in a piece to be repaired, intake, work in progress, completed, schedule pickup up, the second type of client is someone that is ordering a custom made piece, the work flow is as follows: client can find us online and book a free consultation, a consultation can be scheduled Monday to Sunday from 10am to 4pm, client can book online with First Name, Last Name, email and telephone number, the client should get a confirmation email with the time and date chosen, appointments can be cancelled by the client 24hrs ahead of time, once they come for the free consultation intake, send quote for approval, approve quote, send for design, client to approve design, image or wax model, move to next stage, make piece, work complete, ready for delivery, schedule pick up, pick up paramemeters: from Monday to Sunday from 10am to 4pm, increments of 30mins for these appointments, only one a t a time, the customer should get a confirmation SMS with time and date. during intake a unique client order number will be produced, we take client first name, last name, email, telephone number, clinet should have the ability to track their order, notifications should be setup by SMS, we will need consent from client to send SMS, clinet should have the ability to book an appointment once the order is complete, her is the schedule for each type of clinet: repiars can be picked up between 10am and 2pm from Monday to Saturday. client should get a SMS confirmation of their appointment, appoints for repair pickup should be scheduled in encrements of 15mins, no more than 2 appoointements can be scheduled at the same time. all customers should get a reminder 24hrs before their appointment with the abitlity to cancel if needed. the style of the website should be designed for a high end jewelry store, use colors white and dark navy blue with elegant font, clean and user friendly. on the back end store employees should be able to control the workflow as it happens all the way to completion. clients should only see thier own order. i have
